CCOpt Options

CCOpt, like every nonlinear programming solver, has many options. As CCopt is built on MadNLP we point the user to the MadNLP options reference for more details.

Info

One important MadNLP option to note is bound_relax_factor. When solving MPCCs it is important to set this to 0.0 to ensure the nonnegativity of the complementarity is respected.

Relaxation Solver

Relaxation parameter updates

In the relaxation based solver we provide several options of how to drive the relaxation parameter to zero.

CCOpt.AbstractRelaxationUpdate — Type

Method by which the Scholtes relaxation parameter σ is calculated at each iteration.

source
CCOpt.AbstractFixedRelaxationUpdate — Type

Fixed relaxation update methods define a function $σ(μ)$ which is used to calculate the Scholtes relaxation parameter from the barrier parameter.

source
CCOpt.AbstractAdaptiveRelaxationUpdate — Type

Adaptive relaxation update methods update σ independently of μ.

source
CCOpt.ProportionalRelaxationUpdate — Type

Proportional relaxation update which updates $σ = aμ^b$

Fields:

  • sigma_mu_ratio::Real = 1.0: Multiplicative factor $a$.

    Range: $(0,\infty)$

  • sigma_mu_exp::Real = 1.0: Exponent $b$.

    Range: $(0,\infty)$

  • monotone::Bool = false: Enforce only monotone updates.

  • sigma_min::Real = 1.0e-8: Minimum relaxation factor.

    Range: $(0,\infty)$

source
CCOpt.RolloffRelaxationUpdate — Type

Rolloff Relaxation update which updates $σ = cμ^a/(sqrt(μ^a^2)+b)$

Fields:

  • rolloff_slope::Any = 2.0: Slope of rolloff function $a$.

    Range: $(0,\infty)$

  • rolloff_point::Any = 1.0e-6: Beginning of rolloff $b$.

    Range: $(0,\infty)$

  • rolloff_max::Any = 1.0: Initial relaxation value $c$.

    Range: $(0,\infty)$

  • monotone::Bool = false: Enforce only monotone updates.

  • sigma_min::Any = 1.0e-8: Minimum relaxation factor.

    Range: $(0,\infty)$

source
CCOpt.LOQORelaxationUpdate — Type

LOQO based algorithm for adaptively selecting the Scholtes relaxation parameter σ.

$ξ = (n_{cc}min(x₁,x₂))/(x₁ᵀx₂)$

$k = γ*min((1-r)(1-ξ)/ξ, 2)³$

$σ = k(x₁ᵀx₂)/ncc$

Fields:

  • gamma::Any = 0.05: Scale factor $\gamma$.

    Range: $(0,\infty)$

  • gamma_min::Any = 1.0e-5: Minimum reduction factor.

    Range: $(0,\infty)$

  • mu_factor::Any = 1.0e-5

  • r::Any = 0.95: Step length parameter $r$.

    Range: $(0,1.0)$

  • sigma_min::Any = 1.0e-8: Minimum relaxation factor.

    Range: $(0,\infty)$

source
CCOpt.ScheduledRelaxationUpdate — Type

A scheduled update for σ, that is the Fiacco-McCormick rule is applied when the RNLP(σ) is solved to a target accuracy. The target accuracy is calculated as a piecewise function: base accuracy if σ > accuracy shoulder, and ((target accuaracy - base accuracy)/(target accuracy - accuracy shoulder))*σ otherwise. This is done independently of the μ (barrier parameter) update.

Fields:

  • base_accuracy::Any = 0.001

  • target_accuracy::Any = 1.0e-8

  • accuracy_shoulder::Any = 0.0001

  • sigma_linear_decrease_factor::Any = 0.1

  • sigma_superlinear_decrease_power::Any = 1.9

  • sigma_init::Any = 1.0

  • sigma_min::Any = 1.0e-8

source

Endgame strategy

When approaching a solution of an MPCC using a progressively tighter relaxation, the problem of solving the linearized KKT system can become quite difficult. We implement a safeguarding heuristic for this which selectively relaxes the lower bounds of the complementarity variables, based on multiplier estimates.

CCOpt.AbstractEndgameStrategy — Type

Strategies taken once an accuracy threshold is reached in order to promote convergence.

source
CCOpt.NoEndgameStrategy — Type

No special strategy is used.

source
CCOpt.RelaxLBEndgameStrategy — Type

Relaxes the complementarity lower bounds when: duinf ≤ relaxthreshold the corresponding estimated mpec multiplier is negative (the scholtes bound is active) identified by the multiplier being smaller than μ^tau.

Fields:

  • delta_max::Any = 0.0001: Maximum lower bound relaxation.

    Range: $[0.0,\infty)$

  • min_delta_inc_factor::Any = 1.1: Minimum factor of additional relaxation which is applied. If this is not exceeded then we do not modify the lower bound.

    Range: $[0.0,\infty)$

  • tau::Any = 0.4: Exponent applied to the barrier parameter which is used as the threshold at which a bound is considered active.

    Range: $(0.0,1.0)$

source

Q-Regularization

In order to regularize the non-convex contribution of the relaxed complementarity constraints to the Hessian of the Lagrangian function, we provide two choices of specialized algorithm:

  • critical_rho: use a maximal factor (in [0,1]) which makes each two by two complementarity hessian positive definite.
  • eigenvalue_decomposition: projects the matrix into the space of positive matrices by clipping the minimum eigenvalue.

List of Options

Relaxation Solver

CCOpt.RelaxationOptions — Type

Primary options structure for the CCOpt relaxation based solver. This contains options related to the handling of complementarity constrants and RelaxationSolver related logging.

Fields:

  • relaxation::Type = ScholtesRelaxation: Type of relaxation to apply. The only non-experimental relaxation is the ScholtesRelaxation.
  • use_specialized_barrier_update::Bool = false: Whether the adaptive barrier update rules implemented in MadNLP include upper level complementarity residuals.
  • relaxation_update::CCOpt.AbstractRelaxationUpdate{T} where T<:Real = ProportionalRelaxationUpdate(): Relaxation update type. See the section on Relaxation parameter updates for more details.
  • sigma_min::Real = 1.0e-8: Minumum value the relaxation parameter is allowed to take.
  • delta_init::Real = 0.0: Initial lower bound relaxation for the TwoSidedRelaxation.
  • endgame_threshold::Real = 1.0e-6: Primal-dual stationarity tolerance that needs to be achieved to activate the endgame strategy.
  • endgame_strategy::CCOpt.AbstractEndgameStrategy{T} where T<:Real = NoEndgameStrategy{Float64}(): What endgame strategy to use to improve the robustness of solver convergence when near to the solution.
  • respect_comp_bounds::Bool = false: Whether the MadNLPOptions.bound_relaxation should be ignored for complementarity variables.
  • center_complementarities::Bool = false: Whether complementarity variables are initialized using a custom procedure instead of the standard bound-push. This places $x_1$ and $x_2$ on the line $x_1 = x_2$.

  • centering_factor::Real = 0.5: At which fraction of the distance between $(0,0)$ and $(\sqrt{\tau},\sqrt{\tau}$ the centering initialization places the complementarity variables.

    Range: $[0, 1.0]$

  • kkt_regularization::Symbol = :vicente_wright: What KKT regularization to use near the solution.

    • :vicente_wright: adjusts variables away from their bounds to reduce the ill conditioning of the KKT matrix.
    • :none: applies no regularization.

  • q_regularization::Symbol = :none: How to regularize the indefinite contibutiion of the complementarity constraints to the Hessian of the Lagrangian.

    • :none: Does no regularization.
    • :critical_rho: Clips each Lagrange multiplier to the critical value maintaining a threshold positive definiteness.
    • :eigenvalue_decomposition: Project each 2 by 2 matrix to the space of Positive semi-definite matrices, by cliping their eigenvalues to [min_eig_value, max_eig_value].

  • mu_thresh::Real = 5.0e-6: Threshold at which the kkt_regularization option is applied.

    Range: $[0, \infty]$.

  • eta_factor::Real = 0.1

  • min_eig_value::Real = 0.0001: Minimum allowed eigenvalue for the eigenvalue decomposition based q_regularization.

    Range: $(0, \infty]$

  • max_eig_value::Real = Inf: Maximum allowed eigenvalue for the eigenvalue decomposition based q_regularization.

    Range: $(0, \infty]$

  • critical_rho_factor::Real = 0.99: Factor of the critical multiplier to set for the regularized blocks of $Q$.

    Range: $(0.0, 1.0)$

  • min_reg_mu::Real = 5.0e-6: Lower bound of the barrier parameter below which q_regularization is disabled.

    Range: $(0.0, \infty)$

  • reset_slacks_on_update::Bool = false

  • output_file::String = ""

  • print_level::MadNLP.LogLevels = MadNLP.INFO

  • file_print_level::MadNLP.LogLevels = MadNLP.INFO

  • iterates_fname::String = ""

Penalty Solver

CCOpt.PenaltyOptions — Type

Primary options structure for the CCOpt penalty based solver. This contains options related to the handling of complementarity constrants and PenaltySolver related logging.

Fields:

  • penalty::Type = Ell1Relaxation: The penalty formulation to use. The Ell1Relaxation is the only non-experimental option.

  • rho_0::Real = 1.0: Initial penalty parameter.

    Range $[0.0,\infty]$

  • rho_max::Real = 1.0e10: Maximum penalty parameter.

    Range $[0.0,\infty]$

  • rho_growth_rate::Real = 10.0: Factor by which the penalty is increased when stationarity is achieved without complementarity feasibility.

    Range $(0.0,\infty]$

  • gamma::Real = 0.4: Exponent applied to the current barrier parameter $\mu$ to get the expected complementarity reduction.

    Range $(0.0, 1.0]$

  • dynamic_rho_update::Bool = true: Whether the dynamic penalty method of Leyffer et al. is used.

  • comp_history_length::Int64 = 10: How many of the previous complementarity residuals to test for sufficient decrease.

    Range: Integers $[1,\infty]$

  • eta_dynamic_update::Real = 0.99: Factor of sufficient decrease required to not increase the penalty value in the dynamic update algorithm.

    Range: $(0.0,\infty)$

  • q_regularization::Symbol = :critical_rho: How to regularize the indefinite contibutiion of the complementarity constraints to the Hessian of the Lagrangian.

    • :none: Does no regularization.
    • :critical_rho: Clips the penalty for each complementarity to the critical value maintaining a threshold positive definiteness.
    • :eigenvalue_decomposition: Project each 2 by 2 matrix to the space of Positive semi-definite matrices, by cliping their eigenvalues to [min_eig_value, max_eig_value].

  • min_eig_value::Real = 1.0e-8: Minimum allowed eigenvalue for the eigenvalue decomposition based q_regularization.

    Range: $(0, \infty]$

  • max_eig_value::Real = Inf: Maximum allowed eigenvalue for the eigenvalue decomposition based q_regularization.

    Range: $(0, \infty]$

  • critical_rho_factor::Real = 0.99: Factor of the critical multiplier to set for the regularized blocks of $Q$.

    Range: $(0.0, 1.0)$

  • min_reg_mu::Real = 5.0e-6: Lower bound of the barrier parameter below which q_regularization is disabled.

    Range: $(0.0, \infty)$

  • max_reg_mu::Real = 0.1

  • output_file::String = ""

  • print_level::MadNLP.LogLevels = MadNLP.INFO

  • file_print_level::MadNLP.LogLevels = MadNLP.INFO
