JuMP Tutorial

On this page we provide a brief documentation for how to use CCOpt with the JuMP modelling tool.

Prerequisites

In order to use CCOpt to solve complementarity problems modelled in JuMP you need to first install the required packages:

using JuMP
using MathOptComplements
using NLPModelsJuMP
using CCOpt

The package MathOptComplements in particular provides the required reformulations which take MOI.Complments constraints applies the necessary reformulation to the structure of problem required by CCOpt.

Modelling

model = Model()
@variable(model, z[1:2] >= 0)
@objective(model, Min, z[1] + z[2])
@constraint(model, c1, z[2]^2 >= 1)
@constraint(model, comp, [z[1], z[2]] ∈ MOI.Complements(2))
println(model)
Min z[1] + z[2]
Subject to
 c1 : z[2]² ≥ 1
 comp : [z[1], z[2]] ∈ MathOptInterface.Complements(2)
 z[1] ≥ 0
 z[2] ≥ 0

Modelling an MPCC in JuMP is done through the use of ∈ MOI.Complements(2). Note that mixed complementarity constraints are reformulated to standard complementarity constraints, as these are not supported directly by CCOpt.

Solving

MathOptComplements.Bridges.add_all_bridges(model)
set_optimizer(model, CCOpt.Optimizer)
JuMP.optimize!(model)
